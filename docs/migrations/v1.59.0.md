# Upgrading to v1.59.0

`v1.59.0` renames the `lint-semgrep` service rules from the `agora-` prefix to `a-novel-`. Agora names
the user-facing products only; the conventions these rules enforce belong to A-Novel's code.

| Before                                    | After                                       |
| ----------------------------------------- | ------------------------------------------- |
| `agora-must-open-span`                    | `a-novel-must-open-span`                    |
| `agora-no-context-return`                 | `a-novel-no-context-return`                 |
| `agora-dep-interface-method-must-be-exec` | `a-novel-dep-interface-method-must-be-exec` |
| `agora-exec-takes-request-pointer`        | `a-novel-exec-takes-request-pointer`        |
| `agora-no-secret-in-span-attribute`       | `a-novel-no-secret-in-span-attribute`       |
| `agora-no-receiver-mutation`              | `a-novel-no-receiver-mutation`              |
| `agora-error-tag-in-handler`              | `a-novel-error-tag-in-handler`              |

## Do I need to act?

**Only if a `nosemgrep:` comment names one of these rules.** Semgrep no longer matches the old ID, so
the finding it suppressed fails the job again. Rename the ID in the same pull request as the bump.

```diff
-// nosemgrep: agora-dep-interface-method-must-be-exec
+// nosemgrep: a-novel-dep-interface-method-must-be-exec
```
