# Upgrading to v1.73.0

`generic-actions/lint-shell` can shellcheck the Bash `run:` steps of a repository's workflows and
composite actions. actionlint reads workflows only, so outside this repository no check read the
Bash of a composite action.

## Do I need to act?

**Recommended for a repository with composite actions under `.github/actions`:** a-novel/infra and
the services. Nothing changes until a caller sets `run_steps`.

## Lint the Bash run steps

Pass the manifests whose steps to lint as globs:

```yaml
# Before
- uses: a-novel-kit/workflows/generic-actions/lint-shell@v1.72.0
  with:
    # renovate: datasource=custom.shellcheck depName=koalaman/shellcheck
    version: "0.11.0"
    sha256: "8c3be12b05d5c177a04c29e3c78ce89ac86f1595681cab149b65b97c4e227198"

# After
- uses: a-novel-kit/workflows/generic-actions/lint-shell@v1.73.0
  with:
    # renovate: datasource=custom.shellcheck depName=koalaman/shellcheck
    version: "0.11.0"
    sha256: "8c3be12b05d5c177a04c29e3c78ce89ac86f1595681cab149b65b97c4e227198"
    run_steps: .github/actions/*/action.yml .github/workflows/*.yaml
```

- **A repository whose actionlint runs shellcheck passes its actions only.** a-novel/infra sets
  `run_steps: .github/actions/*/action.yaml`, since listing its workflows would report each finding
  twice.
- **service-genai, service-json-keys and service-template have composite actions and no
  `lint-shell` job.** Add one first, as service-authentication's `main.yaml` does.
- **The tracked `*.sh` files are still linted.** `paths` keeps its meaning, and `run_steps` adds the
  extracted steps to it.

Each step is linted as its own script, with SC2016 off: jq and GraphQL quote literal `$variables` on
purpose. Every GitHub expression reads as a set variable, so an unquoted one is reported like any
unquoted variable. Move it to the step's `env:`, as the fleet does everywhere else.

A finding names the step by its manifest path and index, counted from 0, such as
`github_actions_tofu_action.yaml-5.sh`. Its line numbers count the script's header first: the
shebang, the directive and one export per variable.

The extraction needs yq v4, which GitHub's Ubuntu images ship. Globs that match no file fail the
step.
