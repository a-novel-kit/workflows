# Upgrading to v1.37.0

`v1.37.0` removes four composite actions that no workflow in either organization calls. Everything
else in the release is internal or additive: faster, deterministic caches for the Go, pnpm and
Docker actions, and fixes across the landing, release and audit actions.

Removing the actions is a small breaking change, since nothing calls them, so it ships as a minor.

## Do I need to act?

**Only if a workflow references one of the removed actions.** None of the 215 workflow files across
`a-novel` and `a-novel-kit` did when this release was cut, so in-org repos need nothing.

## Remove references to the deleted actions

| Removed action                          | Replacement                                                                                         |
| --------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `generic-actions/token-expiry-notify`   | The org-wide sweep in this repo's `token-expiry.yaml`, which already covers every fine-grained PAT. |
| `generic-actions/auto-merge-bot`        | `generic-actions/enable-auto-merge`, which queues the PR as the [Agent] App.                        |
| `github-pages-actions/publish-vuepress` | None; build the site with the project's own script and deploy with `actions/deploy-pages`.          |
| `publish-actions/auto-release`          | `publish-actions/release-core`, the dispatched release flow.                                        |

Delete the step, or switch it to its replacement, in the same change that moves the workflow to
`v1.37.0`. Earlier tags still contain the actions, so a workflow keeps working until it is re-pinned.

## Notes

Expect one slower Go and pnpm run after adopting this release: the Go actions and `setup-node` now
key their caches per action and architecture, so the first default-branch push seeds the new keys.
From then on, only default-branch pushes save the Go, pnpm and Docker layer caches, and other refs
restore the default branch's nearest one, including after a lockfile or `go.sum` change.

`build-actions/docker` gains an optional `mode` input (`service` or `job`); `docker-job` keeps its
inputs and outputs. If a repository passes `cache: false` to an image that now compiles tooling,
such as an apko-based database image, remove it so the build reuses its layers.
