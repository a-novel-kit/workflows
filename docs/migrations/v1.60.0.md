# Upgrading to v1.60.0

`v1.60.0` leaves no bot write that needs a bypass of the release rulesets, so the agent and publish
Apps can leave them (a-novel-kit/stack#609). Only the release App and admins write the default
branch, its tags and its release lines directly.

- **`node-actions/audit` opens a pull request** instead of pushing its fix to the default branch. It
  commits through the API on `chore/deps/audit`, its `branch` input, and opens or updates one pull
  request, titled `chore(security): audit fix`. `client_id` is now required.
- **`backport-run` creates a missing release line as the release App** when its caller passes
  `release_client_id` and `release_private_key`. That run waits at the `release` environment, and
  only when the line is missing. Without them, the agent still creates the line. The managed
  `hotfix.yaml` passes them once its template moves to this release.
- **`notify-pr-run` drops the pull-requests feed.** A person's pull request no longer posts its
  lifecycle. Its merge, and a drop from the merge queue that pings its owner, now post to the
  reviews channel beside its reviews. The `pull_requests_webhook` secret is gone.

## Do I need to act?

**Every `node-audit.yaml` passes the Dependencies App.** The auto-approver approves that App's pull
requests like a Renovate update, so the fix still lands without a person; a pull request from any
other App waits for a review.

```diff
       - uses: a-novel-kit/workflows/node-actions/audit@v1.60.0
         with:
           github_token: ${{ secrets.GITHUB_TOKEN }}
-          app_private_key: ${{ secrets.PUBLISH_BOT_PRIVATE_KEY }}
-          client_id: ${{ vars.PUBLISH_BOT_CLIENT_ID }}
+          app_private_key: ${{ secrets.DEPENDENCY_BOT_PRIVATE_KEY }}
+          client_id: ${{ vars.DEPENDENCY_BOT_CLIENT_ID }}
```

**Every `notify-pr-run` caller stops passing `pull_requests_webhook`** before moving to `v1.60.0`: a
workflow passing a secret the reusable workflow does not declare fails to start. The managed
`notify.yaml` and `notify-reviews.yaml` already pass none.
