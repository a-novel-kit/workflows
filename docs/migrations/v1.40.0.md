# Upgrading to v1.40.0

`v1.40.0` adds a shared translation gate: `node-actions/lint-translations` checks a platform's
catalogs, and `generic-actions/approve-translations` keeps its two approval labels honest.

## Do I need to act?

**Only in platforms with translation catalogs.** Every other repository needs nothing.

The gate checks three things. Structure failures always block. Gaps (translations the branch left
empty) and drift (source messages the branch changed while their translations did not) block unless
the PR carries `allow-incomplete-translations` or `allow-translation-drift`.

## Provide the scripts

The action runs three package scripts, which inputs can rename:

```json
{
  "i18n:structure": "pnpm i18n:extract:check && pnpm i18n:types:check && pnpm i18n:unused",
  "i18n:gaps": "nodelib-i18n-changes gaps --source en",
  "i18n:drift": "nodelib-i18n-changes drift --source en"
}
```

`nodelib-i18n-changes` ships with `@a-novel-kit/nodelib-config` 1.9.0. The action appends
`--base origin/<default branch>` to the gap and drift scripts.

## Add the job

Skip it on the default branch, which has nothing to compare against. A merge group checks structure
only, because a group cannot carry a gap or drift that its PRs did not each report.

```yaml
lint-translations:
  if: github.ref != 'refs/heads/master'
  runs-on: ubuntu-latest
  permissions:
    contents: read
    packages: read
    pull-requests: read
  steps:
    - uses: a-novel-kit/workflows/node-actions/lint-translations@v1.40.0
      with:
        github_token: ${{ secrets.GITHUB_TOKEN }}
        app_private_key: ${{ secrets.DEPENDENCY_BOT_PRIVATE_KEY }}
        client_id: ${{ vars.DEPENDENCY_BOT_CLIENT_ID }}
```

## Add the trusted caller

Create `.github/workflows/translations.yaml` on the default branch. It reruns the check when a label
changes, and removes both labels when a push changes a catalog under `catalogs`
(default `src/lib/i18n/locales/`). It never checks out PR code.

```yaml
name: translations

on: # zizmor: ignore[dangerous-triggers] Reads labels and reruns a check; never checks out or runs PR code.
  pull_request_target:
    types: [labeled, unlabeled, synchronize]

permissions: {}

jobs:
  approval:
    runs-on: ubuntu-latest
    timeout-minutes: 30
    concurrency:
      group: translations-${{ github.event.pull_request.number }}
      cancel-in-progress: false
    permissions:
      actions: write
      contents: read
      pull-requests: write
    steps:
      - uses: a-novel-kit/workflows/generic-actions/approve-translations@v1.40.0
        with:
          github_token: ${{ github.token }}
```

## Finish

Create both labels, then run `a-novel repo update` on the default branch so `lint-translations`
becomes a required check.
