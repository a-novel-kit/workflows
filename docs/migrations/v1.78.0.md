# Upgrading to v1.78.0

Three inputs move to snake_case, the convention every other input follows, and `build-actions/docker`
takes over `build-actions/docker-job`, which only ran it in job mode. The old names keep working in this
release and log a deprecation warning. A later release removes them.

## Do I need to act?

**Recommended, before the removal.** Nothing changes in what a job does. A step still on an old name
logs a warning that names it, and the daily CI digest collects the warnings of the default branches.
Steps that set both names use the new one. To list the steps to review in a repository:

```bash
grep -rn -A12 -E 'build-actions/docker(-job)?@|go-actions/lint-go@' .github/workflows
```

## Rename the kebab-case inputs

| Action                 | Before              | After               |
| ---------------------- | ------------------- | ------------------- |
| `go-actions/lint-go`   | `working-directory` | `working_directory` |
| `build-actions/docker` | `secret-envs`       | `secret_envs`       |
| `build-actions/docker` | `secret-files`      | `secret_files`      |

```yaml
# Before
- uses: a-novel-kit/workflows/go-actions/lint-go@v1.77.1
  with:
    working-directory: cli

# After
- uses: a-novel-kit/workflows/go-actions/lint-go@v1.78.0
  with:
    working_directory: cli
```

## Replace `docker-job` with `docker` in job mode

`docker` with `mode: job` waits for the test container to exit 0, then tags scheduled builds `nightly`,
as `docker-job` did. Change the action and add `mode: job`. Every other input keeps its name, except
`secret-envs` and `secret-files`, which become `secret_envs` and `secret_files`. The `digest` and
`imageid` outputs and the job's permissions stay the same.

```yaml
# Before
- uses: a-novel-kit/workflows/build-actions/docker-job@v1.77.1
  with:
    file: builds/migrations.Dockerfile
    image_name: ${{ github.repository }}/jobs/migrations
    github_token: ${{ secrets.GITHUB_TOKEN }}

# After
- uses: a-novel-kit/workflows/build-actions/docker@v1.78.0
  with:
    mode: job
    file: builds/migrations.Dockerfile
    image_name: ${{ github.repository }}/jobs/migrations
    github_token: ${{ secrets.GITHUB_TOKEN }}
```

The migration has landed when the job's run shows no deprecation warning.

## Notes

The removal of the old names and of `docker-job` ships once no repository uses them, with its own guide
([a-novel-kit/workflows#622](https://github.com/a-novel-kit/workflows/issues/622)).
