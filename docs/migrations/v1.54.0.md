# Upgrading to v1.54.0

`v1.54.0` removes the reusable `watchdog.yaml`. It never left dry-run in either org, and its callers
are gone: a-novel-kit/.github#309 and a-novel/.github#416. Failed hotfixes and Epic rollbacks still
escalate through their own workflows.

## Do I need to act?

**Only if a repository still calls it.** Delete the caller before moving its pins to `v1.54.0`; a
workflow that references a missing reusable workflow fails to start. Its `ESCALATE_PUSH_WEBHOOK`
secret stays: every `hotfix.yaml` passes it to `escalate`.
