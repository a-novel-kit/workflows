# Upgrading to v1.70.0

`go-actions/test-go` no longer accepts `filter_patterns` or `filter_extra_patterns`, which
[v1.69.0](./v1.69.0.md) deprecated. A shell pipeline could run any command in the step, while
`include` and `exclude` stay data.

## Do I need to act?

**Yes**, if a `test-go` step still sets either input. GitHub reports an unexpected input and ignores
it, so the step would test packages the pipeline used to drop. Replace each pipeline with `include`
or `exclude` as [v1.69.0](./v1.69.0.md) shows, then move to this release. Every fleet service has
already moved.
