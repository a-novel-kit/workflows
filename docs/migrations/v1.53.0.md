# Upgrading to v1.53.0

`v1.53.0` lets a platform run its `main` workflow on pull requests, as the services do, instead of on
every branch push. On a pull request, `GITHUB_SHA` is GitHub's temporary merge commit, so the
screenshot and translation gates now work from the pull request's head:

- `test-playwright` and `lint-translations` check out the head, so the commit tested is the commit a
  label approves.
- The `visual-comparison` status, its proof and its Drive batch name the head. The merge queue
  accepts proofs from `pull_request` runs as it does from branch pushes.
- A run is approved only while its pull request is open, targets `master`, comes from the same
  repository and still points at the tested head.
- `lint-translations` checks gaps and drift on pull requests too. On the run for a push it ignores
  both approval labels, since each approved an earlier head.
- `approve-translations` and `approve-playwright` rerun nothing for a `pull_request` run that a label
  change already restarted. `approve-playwright` reruns a browser job only when it began before the
  approval receipt.

Branch-push callers keep working unchanged.

## Do I need to act?

**Only to move a platform to pull request CI.** Then, in its `main.yaml`:

```yaml
on:
  push:
    branches: [master]
    tags-ignore: ["**"]
  pull_request:
    types: [opened, synchronize, reopened, labeled, unlabeled]
  merge_group:

concurrency:
  group: ${{ github.workflow }}-${{ github.event.pull_request.number || github.run_id }}
  cancel-in-progress: true
```

The concurrency group cancels a pull request's superseded run, so an older run cannot overwrite a
newer comparison; master and merge-queue runs get their own group and always finish.

Its `visual-tests.yaml` follows `main` runs from pull requests:

```yaml
github.event.workflow_run.event == 'pull_request' &&
github.event.workflow_run.head_repository.full_name == github.repository
```

The visual-test candidate identity must also accept `pull_request` tokens for pull requests into
`master`; a-novel/infra configures it in `bootstrap/visual-tests.tf`.

## What reviewers see

- A branch without a pull request gets no run, and a pull request with merge conflicts gets none until
  it is rebased. Open a draft pull request for CI on work in progress.
- Adding `allow-screenshot-change` or a translation label starts a new run for the head.
