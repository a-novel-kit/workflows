# Upgrading to v1.74.0

`security-actions/lint-semgrep` and `security-actions/lint-workflows` run their scanner image by
digest. A tag names whatever image its publisher pushed last, so whoever takes over the publisher's
registry account can change the scanner every repository runs. A digest names one image's bytes.

## Do I need to act?

**Recommended for every repository with a `lint-semgrep` or `lint-workflows` job.** Without a digest,
the action runs the tag and warns, and a later release requires the digest.

## Pin the digest

Write the image digest after the tag in `version`, where Renovate reads it:

```yaml
# Before
- uses: a-novel-kit/workflows/security-actions/lint-workflows@v1.73.0
  with:
    # renovate: datasource=docker depName=ghcr.io/zizmorcore/zizmor
    version: "1.31.1"

# After
- uses: a-novel-kit/workflows/security-actions/lint-workflows@v1.74.0
  with:
    # renovate: datasource=docker depName=ghcr.io/zizmorcore/zizmor
    version: "1.31.1@sha256:42d409dbb851d4c5d35a058cf042b828bea1e3f2884378c526eb0974780e18d9"
```

semgrep 1.182.0 pins `1.182.0@sha256:4a34048c04fef049f71665047f074cffb00cc3d89482f965a5cd151d589237af`.
For another version, the digest is the SHA-256 of the image index the registry serves for the tag:

```bash
index='Accept: application/vnd.oci.image.index.v1+json'
token="$(curl -fsS 'https://ghcr.io/token?scope=repository:zizmorcore/zizmor:pull' | jq -r .token)"
curl -fsS -H "Authorization: Bearer $token" -H "$index" https://ghcr.io/v2/zizmorcore/zizmor/manifests/1.31.1 | sha256sum
token="$(curl -fsS 'https://auth.docker.io/token?service=registry.docker.io&scope=repository:semgrep/semgrep:pull' | jq -r .token)"
curl -fsS -H "Authorization: Bearer $token" -H "$index" https://registry-1.docker.io/v2/semgrep/semgrep/manifests/1.182.0 | sha256sum
```

Make the change with the bump to v1.74.0 or after it. An older Renovate preset reads the whole
`<tag>@sha256:<digest>` as the version, finds no such tag and stops updating the pin.

Renovate then moves the tag and the digest together. An update that keeps the tag and changes the
digest merges on its own, like any image digest. A third-party action's digest update still waits for
a reviewer.
