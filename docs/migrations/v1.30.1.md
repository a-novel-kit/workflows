# Upgrading to v1.30.1

`v1.30.1` centralizes the Renovate baseline and fleet-wide dependency groups in the shared
`generic-actions/renovate` action. It eagerly resolves `config:recommended`, then applies the
A-Novel grouping policy so repository presets cannot split lockfile-sensitive updates again.

## Required consumer change

Update every `a-novel-kit/workflows` action reference in a repository from `v1.30.0` to
`v1.30.1` in one pull request. In that same pull request, remove `config:recommended` from the
repository's `renovate.json`.

Also remove local copies of these fleet policies:

- the broad non-major JavaScript dependency group;
- the pre-1.0 `@a-novel-kit/uikit` family group;
- the Playwright package and container-image group;
- the `vitest` and `@vitest/*` family group;
- the major Vite and Svelte Vite plugin group.

Keep repository-specific manager discovery, generators, formatters, version constraints, safety
rules, and other genuine exceptions. A repository with no exceptions may retain a schema-only
`renovate.json`.

If a caller supplies `allowed_commands` but has no local `postUpgradeTasks`, remove the unused
input. Callers that still run repository-specific generation or formatting tasks must keep their
narrow allowlist.

## Verification

After the consumer pull request lands, dispatch its Renovate workflow once. The run must complete
without configuration or artifact errors. Confirm that routine non-major npm changes share one
branch, Playwright packages and images share a runtime branch, Vitest packages share a family
branch, pre-1.0 uikit updates require review, and major Vite/plugin updates stay together.
