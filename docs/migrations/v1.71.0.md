# Upgrading to v1.71.0

`reconcile-board` no longer runs the render pass, so it drops its `render_dry_run` input, and
`generic-actions/render-epic-status` is removed. The pass rewrote a display-only status table into each
active Epic's issue body. No landing decision read the table, and no caller ever turned its writes on, so
every sweep did the reads and wrote nothing.

## Do I need to act?

**Only if a workflow passes `render_dry_run` to `reconcile-board` or calls `render-epic-status`.** Neither
`.github` caller does, so both organizations need nothing beyond the pin move.

A caller that still passes `render_dry_run` fails to start, because a reusable workflow refuses an input it
does not declare. Delete the input in the same change that moves the pin to `v1.71.0`. Earlier tags still
contain the action, so a workflow that calls it keeps working until it is re-pinned.
